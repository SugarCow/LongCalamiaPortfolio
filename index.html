// Overview

Death Wish is a fast-paced 2D action roguelike inspired by One Finger Death Punch and Shogun Showdown, embracing unapologetic edginess with cinematic influences from Samurai Jack and Kill Bill.

Become the tool of Death and slaughter your way through relentless waves of immortal thralls sent by the betrayers. To deal death, you must live by it — walk its fine line and embrace its presence.

// Enemy Design

Enemies come in many distinct forms, each requiring a different approach: The Assassin, The Spearman, and The Strongarm each bring unique threat patterns and must be countered differently. The game's weapon variety matches this enemy diversity.

// Artistic Direction

Death Wish stylistically pays homage to Samurai Jack and anime manga, featuring manga-esque UI elements such as a health-reactive face representing the player's condition — cycling through Healthy, Damaged, and Death's Door states. Boss UI design reinforces the cinematic tone.

Frag-A-Mole

Engine
Unreal Engine
Year
March 2024
Type
Acerola Game Jam 0

// Overview

Frag-A-Mole is a top-down shoot-em-up pixel art game created during Acerola Game Jam 0 — a two-week competition where contestants relied solely on their own programming, art, music, and non-copyrighted assets.

The goal is to shoot moles of different varieties before they overwhelm you and drain your health. There are 10 distinct enemy types with abilities ranging from shooting, consuming player resources, buffing allies, and spawning additional moles.

// Technical Highlights

Enemy types are stored in an enum accessed by the BP_Enemy Actor. Animations were built using the PaperZD Animation plugin, with state-driven transitions (e.g., Root → Idle on spawn). The spawn grid is generated dynamically via BP_SpawnerGrid with exposed row/column variables — supporting up to 6×6 grids — using a 2D array structure to randomly assign enemy positions.

// Tools Used
Unreal Engine Blueprint Aseprite Audacity PaperZD

[ scream jam 2024 ]

Programmer · Designer · Artist

Hehe Television

Engine
Unreal Engine
Year
February 2024
Jam
Scream Jam 2024 (7 days)
Theme
TV / Don't Touch That Dial
// Overview

A cursed television arrives at your door, sent by your older brother from a mysterious thrift store. Upon turning it on, you encounter a series of disturbing messages. Can you find all the clues to decipher the hidden message?

Inspired by Courage the Cowardly Dog, Where's Waldo, and Salad Fingers, the game's 1-bit aesthetic draws from old black and white cartoons from the 1950s–60s. Channels mix hand-animated Aseprite sprites with royalty-free clips from vintage television.

// Mechanics

Players flip through TV channels, each growing more sinister as the game progresses. Hidden clues appear throughout gameplay duration, not immediately on channel entry. The game ends when all clues are found. Controls were deliberately limited to a single mouse click to keep scope manageable for a solo 7-day effort.

// Personal Reflection

The initial design was a reverse Where's Waldo — spot the entity that doesn't belong. After prototyping, the sprites were too small to be recognizable when shrunk, requiring a full mechanic redesign. This iteration process led to the final hidden-clue format, which received strong positive feedback from players.

Rise Of The Cult

Engine
Godot
Year
January 2024
Team
4 members
Jam Theme
Spreading
// Overview

A Lovecraftian card strategy game set in Victorian-era England. Players lead a cult devoted to an eldritch horror, expanding influence across cities using Fame, cult population, Appeasement, and Money through card play. The God's true nature is kept a mystery — as the game progresses, the monstrous celestial being corrupts the player.

Inspired by Reigns, Papers Please, and Plague Inc., the game ends when the player takes over the world to prepare for the arrival of God.

// Design Philosophy

The jam theme "Spreading" was interpreted figuratively — exploring the dynamics of religion and infamous real-world cults. Research into cult operations shaped the mechanics, including a Doomsday Timeline and the ability to hoax miracles. The warm color palette deviates from typical Lovecraftian blues and purples, giving the deity a fleshy, demonic quality.

// Postmortem

The team unanimously identified UX design as the weakest element — the action tiles (small panels) confused players who were unaware more actions existed. This sparked valuable discussion on adding discovery indicators, and individually the team gained significant experience communicating design ideas effectively.

Mutagenesis

Year
January 2024

// Overview

Mutagenesis is a top-down action game inspired by Ape Out, Superhot, and Carrion. The player is an escaped science project that must consume scientists to evolve. Each type of scientist mutates the player differently, while armed guards with guns and tasers block the path. One hit kills — and time slows when the player stops moving.

// Development Timeline

Day 1 (~10 hours): Scripting in Blueprint to build attack mechanics and the slow-motion system. Day 2 (~15 hours): All art assets created in Aseprite. Day 3: Integration of prototype and art, plus finishing features like friendly-fire slow motion using Unreal's time dilation node.

// Audio Design

Royalty-free SFX were selected for their visceral impact — fleshy squish sounds reinforce the player's monstrous power, while cartoonishly exaggerated enemy gasps add dark comedy. Background music by Mike Dijital (CC BY-NC) captures a Doom-like sense of badassery during combat.

PrisonBreak

Engine
Unity
Year
August 2023
Team
5 members
Language
C#
// Overview

A 1-bit top-down stealth game inspired by classic browser games like "The Classroom." Players are inmates exploiting a prison power outage — navigating darkness while guard and watchtower spotlights sweep the environment. Lightning strikes periodically illuminate the prison, revealing the key and escape route.

// Design Process

Initially designed with fully dark environments, the team pivoted to giving players tools for navigation. A prisoner class system was developed offering distinct playable characters with unique abilities — though scope constraints late in the jam reduced this to a single character with the lightning mechanic instead.

The level design drew from Metroidvania principles — creating interconnected spaces where players revisit earlier areas, building familiarity and cohesion. Switch-and-door systems were planned to guide exploration, though only one instance made the final build.

// Art Direction

All sprites were restricted to a 16×16 grid to achieve a retro 1-bit aesthetic. Multiple character iterations were created and reviewed by the team before settling on a compact design that added charm while reinforcing vulnerability. The animation conveys urgency — the player appears to be frantically escaping imminent danger.

Every Orc Has a Price

Engine
Godot 4.0
Year
August 2023
Type
Personal Project
Language
GDScript
// Overview

A top-down roguelike set in a world where all heroes have fallen to endless Orc hordes. Playing as a merchant, your only weapon is money. Use a coin launcher to shoot coins at Orcs — bribing them to fight for you. Each Orc has a unique recruitment price, and their loyalty wanes over time, ending in a death attributed to shame.

Enemies drop coins and health at intervals, keeping the resource loop alive. Procedural generation ensures each run creates a different layout of trees, fire pits, and tower structures.

// Technical Details

Procedural object generation uses a double for loop to iterate the level grid, assigning percentage-based spawn chances to each object type and generating a random float to determine spawns. Weapon rotation uses Godot's look_at() function to align the weapon with the mouse cursor at all times.

Character art was built on recolored pre-made assets by RGS_Dev, with all other assets created from scratch in Aseprite.

Cafe Rush

Engine
Godot 4.0
Year
July 2023
Type
Personal Project (First Solo)
Language
GDScript
// Overview

A heartwarming cozy cafe serving game inspired by Overcooked and Diner Dash. Serve a stream of customers efficiently before they grow impatient and leave. This was Long's first solo project — every asset, animation, and component was crafted by hand (except the pastries).

// Technical Focus: State Machines

The project's primary goal was showcasing state machine architecture. Both the player and customers are governed by state machines that define behavior at any given moment — Idle, Serving, and Interacting states transition smoothly, ensuring clean gameplay flow.

This structured approach improves code readability by organizing logic according to state, making future features easier to add or modify. The player class maintains distinct states using this system, with clear function separation for long-term maintainability.

CrossyRoad

Engine
Unreal Engine
Year
December 2022
Type
University Final (2 members)
Hours
~50 hours
// Overview

A faithful recreation of the classic mobile game "Crossy Road," built in Unreal Engine with a classmate for the final project of an Intro to Game Development course. All 3D voxel assets were hand-crafted in MagicaVoxel.

// Technical Highlights

Lane spawning is handled by a dedicated Blueprint that randomizes lane types using a "Randomize Lane" node. Each lane has its own trigger zone managing car/log/train spawns and detecting when the player crosses. Tree and rock spawners procedurally fill normal grass lanes. Train crossing lights use Unreal's timeline nodes to create blinking animations. The system supports infinite procedurally scrolling levels.

Typopotamus

Engine
Unreal Engine
Year
April 2023
Type
University Project
Language
Blueprint / UMG
// Overview

An endless tower defense typing game where the player defends against waves of increasingly difficult enemies by typing their assigned words. Enemy size and attack power scale with word length. At the end of each round, players choose from three random power-ups.

// Technical Details

Enemies use a simple AI behavior tree — the BP_Task_Go_To_Player node locates the player and executes an AI Move To function. Input is handled through Unreal's input mapping: each correct character typed removes it from the targeted enemy's word, and a homing fireball targets the correct enemy by name. A fireball material setup drives the visual effect.

The event tick in BP_Player constantly checks for the player's death state and creates a game over widget when triggered. All assets — characters, structures, environment — were created in MagicaVoxel.

Survival Slayer

Engine
Python / Pygame
Year
April 2023
Type
University Group
Tools
Aseprite · Tiled
// Overview

A 2.5D top-down survival slasher coded in Python using Pygame. Players fight off skull-like entities with a collection of weapons and magic spells, each with unique attack sounds. Maps dynamically change over time, introducing new enemy waves to sustain challenge and engagement.

// Technical Details

The Character class initializes player attributes including weapons, magic, movement, and stats, with controls and sprite handling managed here. A UI system displays health, mana, exp, score, and active weapon/magic with color-coded feedback. The Weapon class initializes sprites directionally based on where the player is facing.

Level initialization sets up the screen, level objects, map lists, timer, and background music. Tiled was used for level design, with Aseprite handling all character and environmental sprites.
